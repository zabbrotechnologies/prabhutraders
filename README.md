# Prabhu Traders — MAXYWALK Luxury Leather E-Commerce

Premium handcrafted genuine leather footwear (slippers, mules, sandals) and accessories (belts, wallets) under the registered brand **MAXYWALK**, handcrafted in Avadi, Tamil Nadu, India.

## Features
- 100% Cash on Delivery (COD) Pan-India ordering
- Admin Dashboard for inventory management, order tracking, and statistics
- Fully responsive design (Mobile, Tablet, Laptop, Desktop)
- Firebase Auth & Firestore DB integration

## Stack
- **Frontend**: React 19, Vite, TailwindCSS v4, React Router v7, Zustand, React Hot Toast
- **Backend**: Express API, Firebase Admin SDK, Razorpay SDK
